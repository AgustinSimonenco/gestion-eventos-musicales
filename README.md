# Sistema de Gestión de Eventos Musicales

Trabajo Práctico Integrador — **Algoritmos I**

Software para administrar recitales: gestión de eventos, asignación de artistas, venta de entradas y registro de pagos. Centraliza la administración de eventos y la interacción con los usuarios.

> 🚧 Etapa inicial: por ahora el repositorio contiene solo el análisis y el diseño preliminar.

## Actores

| Actor | Qué puede hacer |
|---|---|
| **Organizador** | Crear, modificar y cancelar eventos. Asignar artistas. |
| **Cliente** | Consultar eventos disponibles, comprar entradas, pagar y ver su historial de compras. |
